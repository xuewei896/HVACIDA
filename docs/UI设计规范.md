# HVACIDA UI 设计规范(Revit 2020 原生风格)

> 目标读者:开发/实现者(含 AI)。
> 设计基准:**1:1 贴近 Revit 2020 自带对话框观感**——浅灰底、系统字体、紧凑间距、Windows 标准控件外观;
> 不追求"现代/炫酷",追求"用户一眼看出这是 Revit 自己的窗口"。
> 关联文档:`HVACIDA_需求分析文档.md`(功能与交互要求,尤其 1.3 与 2.1/2.2.3)、`docs/开发流程.md`(流程)。
> 版本:v1.0(2026-09-10)。本文只做设计,不涉及代码改动。

---

## 1. 设计原则

1. **像 Revit,不像外挂**:优先使用 WPF 标准控件与系统主题外观,不做自绘皮肤、不做渐变/阴影/圆角大色块。
2. **信息密度优先**:工程参数多(大系统约 65 项),采用紧凑行高 + 分节 GroupBox + 双列排布,避免大留白。
3. **输入/结果分离**:左侧输入、右侧结果固定双栏;结果区不随输入滚动,随时可见。
4. **参数可追溯**:UI 展示工程术语,单元格代号(D55/C39/E159…)仅作辅助(见 §6.3),不干扰主视线。
5. **每个窗口必有"确定 / 取消"**(需求 1.3),默认按钮为"确定",Esc 关闭。
6. **一次只做一件事**:拾取空间、拾取墙体等模型交互用独立提示条 + 可取消模态流程,不混在参数编辑里。
7. **原生尺寸**:字号 9pt、按钮高 23px、行高 24px——与 Revit 对话框一致,不用 14pt 以上的"大标题"。

## 2. 视觉基准(Revit 2020 浅色 · 原生)

> 下列为**基准值**;实现时以本机 Revit 2020 实际对话框取色/量距为准(截图取色),差异以 Revit 为准。

| 令牌 | 建议值 | 用途 |

| `Text.Disabled` | `#9A9A9A` | 禁用项 |

| `Input.ReadOnly` | `#F5F5F5` | 只读(模型获取值) |

### 2.2 字体与字号

| 用途 | 字体 | 字号 | 行高 |
|---|---|---|---|
| 全部正文/控件 | `Microsoft YaHei UI`(中文)/ `Segoe UI`(英文数字) | 9pt(12px) | 22–24px |
| 分节标题(GroupBox Header) | 同上 | 9pt 常规 | — |
| 结果区等宽展示(数值/表格) | `Consolas` | 9pt | 20px |
| 窗口标题 | 系统标题栏 | 系统默认 | — |

- 不使用粗体做视觉层级(Revit 原生极少用粗体);分节靠 GroupBox 边框与间距区分。
- 数字右对齐(输入框 `HorizontalContentAlignment=Right`),文本字段左对齐。

### 2.3 尺寸与间距

| 项 | 值 |
|---|---|
| 窗口内容外边距 | 12px |
| 分节之间 | 10px |
| 分节内控件行距 | 4px |
| 标签列宽 | 190px(固定,保证两列对齐) |
| 数值输入框 | 宽 130px,双列表单中相邻两列间距 16px |
| 文本输入框(名称类) | 宽 250px |
| 按钮高 | 23px;标准按钮最小宽 75px;"确定/取消"宽 88px |
| 底部操作栏高 | 44px(含 10px 上下内边距 + 细分隔线) |
| GroupBox 内边距 | 8px |

### 2.4 控件规格

| 控件 | 规格 |
|---|---|
| **Button** | Windows 标准外观;**圆角 2px**、极浅竖向渐变、内高光;悬停淡蓝底 `Accent.Soft` + 蓝边,hover/active 分明;默认按钮(确定)蓝色描边 + 内侧浅蓝描边;危险/清空类操作放左侧且需二次确认 |
| **TextBox** | 高 23px;数值型右对齐;只读(模型取值)用 `Input.ReadOnly` 底色 + 灰字 + ToolTip 说明"来自模型空间";悬停蓝边、聚焦 `Accent.Blue` 边框 + 2px 焦点环 |
| **ComboBox** | 高 23px;只读下拉(DropDownList 样式),不用可输入下拉 |
| **GroupBox** | 1px `Border.Default` 边框 + 圆角 3px;标题左侧 3px `Accent.Blue` 竖条,标题不加底色 |
| **RadioButton / CheckBox** | 13px 方形/圆形,标签紧跟 8px 间距;系统类型选择用 RadioButton(互斥且项少);勾选色取 `Accent.Blue` |
| **ListBox(空间列表)** | 白底、单行选择高亮 `Accent.Selected` + 左侧 3px `Accent.Blue` 竖条、行高 24px、带垂直滚动 |
| **DataGrid / 表格** | 白底 + 网格线 `Border.Soft`;表头浅灰 `#EFEFEF`(极浅渐变 + 内高光);偶数行极浅斑马纹 `#FBFCFD`;行悬停淡蓝;数值列右对齐;禁用排序箭头 |
| **TabControl** | 仅用于"参数 / 结果 / 记录"这类对等视图;不用 Tab 做分步向导 |
| **ScrollViewer** | 仅纵向滚动;滚动条窄条样式(12px 轨道、6px 圆角滑块、悬停加深);内容区宽度自适应(不出现横向滚动) |
| **ToolTip** | 用于单元格代号、单位、默认值来源的补充说明(Revit 用户习惯) |
| **状态文字** | 底部操作栏内、按钮右侧,9pt,成功绿/失败红,超长省略号 + ToolTip 全文 |

### 2.5 视觉打磨规格(2026-09-11 原型视觉升级)

> 目的:在**不改变 Revit 原生观感**的前提下提升精致度——统一圆角、极浅渐变、状态反馈与层次阴影,避免"平面色块堆叠"。原型以 CSS 令牌实现,落地到 WPF 用等价资源。

| 项 | 规格 | WPF 落地方式 |
|---|---|---|
| 圆角 | 窗口 4px;按钮/输入框/列表/卡片 2–3px | `Border.CornerRadius` / 控件 `Template` 圆角 |
| 层次阴影 | 窗口两层投影;卡片/按钮 1px 投影 | `DropShadowEffect`(浅)/ 分层 `Border` |
| 渐变 | 仅标题栏、表头、底栏、工具栏、画布用**极浅**竖向渐变(明度差 ≤ 8%) | `LinearGradientBrush` 令牌资源 |
| 状态反馈 | 悬停:底色 `Accent.Soft` + 蓝边;按下:再深一档 + 内阴影;禁用:灰字灰底 | `VisualStateManager`(Normal/MouseOver/Pressed/Disabled) |
| 焦点环 | 键盘聚焦 2px `rgba(0,120,215,.35)` 外环;鼠标点击不显环 | `FocusVisualStyle` + `KeyboardNavigation` |
| 强调条 | 分节标题、卡片表头、选中项左侧 3px `Accent.Blue` 竖条 | `Border` 左边框 |
| 过渡动效 | 120ms ease-out(仅底色/边框/阴影);窗口打开 120ms 淡入 | `VisualStateManager` + `Storyboard`(≤150ms) |
| 动效禁用 | 系统"关闭动画"时全部禁用;不做位移动画 | 监听 `SystemParameters.ClientAreaAnimation` |

## 3. 统一窗口框架(所有功能窗共用)

### 3.1 结构

```
┌──────────────────────────────────────────────────────────────┐
│ [提示条:可选,浅黄底,一句话说明本窗用途/注意]                 │  ← 可选
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                     内容区(可纵向滚动)                       │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ [扩展按钮区(左)]                          [确定] [取消(右)]   │  ← 固定底栏
│ 状态文字:xxx                                                  │
└──────────────────────────────────────────────────────────────┘
```

- **底栏左**:本窗特有动作(如"从模型拾取空间""恢复默认参数""导出计算书")。
- **底栏右**:**确定**在左、**取消**在最右(与 Revit/Windows 一致);确定=主操作,取消=关闭不保存。
- 只读展示类窗口(如计算书预览)可把"取消"改为"关闭"。

### 3.2 行为规范

| 项 | 规范 |
|---|---|
| Owner | 必须为 Revit 主窗口(`WindowInteropHelper.Owner`),保证任务栏/焦点行为正确 |
| 模态 | `ShowDialog()` 模态;计算类窗口计算时禁用主按钮并显示忙碌光标 |
| 显示位置 | `CenterOwner`(回退 CenterScreen) |
| 尺寸 | 默认见 §4 各窗;可缩放(`ResizeMode=CanResize`),最小尺寸=默认×0.8;记录上次尺寸(可选) |
| 键盘 | Enter=确定(默认按钮),Esc=取消/关闭,Tab 顺序=视觉顺序 |
| 关闭确认 | 仅当"有未保存的参数修改"时提示"放弃修改?" |
| DPI | 支持 PerMonitorV2;所有尺寸用设备无关单位,不写死像素字体 |

## 5. 与 Revit 模型交互规范

1. **拾取空间**:底栏或字段旁按钮 → 隐藏本窗(`Hide()`)+ 状态提示条 → `Selection.PickObject(ObjectType.Element, filter)` 循环选择 → 完成后恢复窗口并回填;Esc 取消则保留原值并提示"已取消拾取"。
2. **拾取墙体**(小系统外墙长度):同上,`ISelectionFilter` 只允许墙;支持多选,实时累计长度显示在提示条("已选 3 段,共 32.5 m"),确认后回填。
3. **反馈**:拾取过程中窗口必须隐藏或半透明,避免遮挡模型;提示条文案包含"Esc 取消"。
4. **失败处理**:拾取到无面积/无高度的空间 → 该字段留空并标红 + 说明"该空间缺少面积参数,请在模型中检查"。
5. **计算线程**:同步计算(当前规模秒级);超过 1 秒显示忙碌光标;超过 5 秒显示进度窗(可取消)。

## 7. 校验、错误与进度

| 场景 | 处理 |
|---|---|
| 必填为空(如客流) | 输入框标红 + 底栏错误文字 + 焦点定位到首个错误字段;"计算"仍可点,但结果区提示"缺少必填参数" |
| 数值越界(负数、>阈值) | 同上,提示具体范围 |
| 几何为 0 | 允许计算但结果区提示"站厅/站台面积为 0,结果无意义" |
| 除零/退化(湿负荷=0) | **不弹错**;结果按保护规则(焓差过小记 0)并加灰字说明 |
| 计算异常 | 结果区显示简要错误 + "查看详情"展开堆栈;**不弹系统错误框** |
| 保存失败(文件占用等) | 顶栏红色状态条,保留输入不清空 |
