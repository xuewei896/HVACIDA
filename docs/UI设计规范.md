# HVACIDA UI 设计规范(Revit 2020 原生风格)

> 目标读者:开发/实现者(含 AI)。
> 设计基准:**1:1 贴近 Revit 2020 自带对话框观感**——浅灰底、系统字体、紧凑间距、Windows 标准控件外观;
> 不追求"现代/炫酷",追求"用户一眼看出这是 Revit 自己的窗口"。
> 关联文档:`HVACIDA_需求分析文档.md`(功能与交互要求,尤其 1.3 与 2.1/2.2.3)、`docs/开发流程.md`(流程)。
> 版本:v1.0(2026-09-10)。本文只做设计,不涉及代码改动。

---

## 1. 设计原则

1. **像 Revit,不像外挂**:优先使用 WPF 标准控件与系统主题外观,不做自绘皮肤、不做渐变/阴影/圆角大色块。
2. **信息密度优先**:工程参数多(大系统约 65 项),采用紧凑行高 + 分节 GroupBox + 双列排布,避免大留白。
3. **输入/结果分离**:左侧输入、右侧结果固定双栏;结果区不随输入滚动,随时可见。
4. **不体现内部编号**:界面一律用工程术语,**不出现公式文档单元格编号**(D55/C39/E159…);确需追溯时只在**悬停提示**里给出(见 §6.3)。
5. **每个窗口必有"确定 / 取消"**(需求 1.3),默认按钮为"确定",Esc 关闭。
6. **一次只做一件事**:拾取空间、拾取墙体等模型交互用独立提示条 + 可取消模态流程,不混在参数编辑里。
7. **原生尺寸**:字号 9pt、按钮高 23px、行高 24px——与 Revit 对话框一致,不用 14pt 以上的"大标题"。

## 2. 视觉基准(Revit 2020 浅色 · 原生)

> 下列为**基准值**;实现时以本机 Revit 2020 实际对话框取色/量距为准(截图取色),差异以 Revit 为准。

### 2.2 字体与字号

| 用途 | 字体 | 字号 | 行高 |
|---|---|---|---|
| 全部正文/控件 | `Microsoft YaHei UI`(中文)/ `Segoe UI`(英文数字) | 9pt(12px) | 22–24px |
| 分节标题(GroupBox Header) | 同上 | 9pt 常规 | — |
| 结果区等宽展示(数值/表格) | `Consolas` | 9pt | 20px |
| 窗口标题 | 系统标题栏 | 系统默认 | — |

- 不使用粗体做视觉层级(Revit 原生极少用粗体);分节靠 GroupBox 边框与间距区分。
- 数字右对齐(输入框 `HorizontalContentAlignment=Right`),文本字段左对齐。

### 2.3 尺寸与间距

### 2.4 控件规格

| 控件 | 规格 |
|---|---|
| **Button** | Windows 标准外观;**圆角 2px**、极浅竖向渐变、内高光;悬停淡蓝底 `Accent.Soft` + 蓝边,hover/active 分明;默认按钮(确定)蓝色描边 + 内侧浅蓝描边;危险/清空类操作放左侧且需二次确认 |
| **TextBox** | 高 23px;数值型右对齐;只读(模型取值)用 `Input.ReadOnly` 底色 + 灰字 + ToolTip 说明"来自模型空间";悬停蓝边、聚焦 `Accent.Blue` 边框 + 2px 焦点环 |
| **ComboBox** | 高 23px;只读下拉(DropDownList 样式),不用可输入下拉 |
| **GroupBox** | 1px `Border.Default` 边框 + 圆角 3px;标题左侧 3px `Accent.Blue` 竖条,标题不加底色 |
| **RadioButton / CheckBox** | 13px 方形/圆形,标签紧跟 8px 间距;系统类型选择用 RadioButton(互斥且项少);勾选色取 `Accent.Blue` |
| **ListBox(空间列表)** | 白底、单行选择高亮 `Accent.Selected` + 左侧 3px `Accent.Blue` 竖条、行高 24px、带垂直滚动 |
| **DataGrid / 表格** | 白底 + 网格线 `Border.Soft`;表头浅灰 `#EFEFEF`(极浅渐变 + 内高光);偶数行极浅斑马纹 `#FBFCFD`;行悬停淡蓝;数值列右对齐;禁用排序箭头 |
| **TabControl** | 仅用于"参数 / 结果 / 记录"这类对等视图;不用 Tab 做分步向导 |
| **ScrollViewer** | 仅纵向滚动;滚动条窄条样式(12px 轨道、6px 圆角滑块、悬停加深);内容区宽度自适应(不出现横向滚动) |
| **ToolTip** | 用于单元格编号(悬停追溯)、单位、默认值来源的补充说明(Revit 用户习惯) |
| **状态文字** | 底部操作栏内、按钮右侧,9pt,成功绿/失败红,超长省略号 + ToolTip 全文 |

### 2.5 视觉打磨规格(2026-09-11 原型视觉升级)

> 目的:在**不改变 Revit 原生观感**的前提下提升精致度——统一圆角、极浅渐变、状态反馈与层次阴影,避免"平面色块堆叠"。原型以 CSS 令牌实现,落地到 WPF 用等价资源。

| 项 | 规格 | WPF 落地方式 |
|---|---|---|
| 圆角 | 窗口 4px;按钮/输入框/列表/卡片 2–3px | `Border.CornerRadius` / 控件 `Template` 圆角 |
| 层次阴影 | 窗口两层投影;卡片/按钮 1px 投影 | `DropShadowEffect`(浅)/ 分层 `Border` |
| 渐变 | 仅标题栏、表头、底栏、工具栏、画布用**极浅**竖向渐变(明度差 ≤ 8%) | `LinearGradientBrush` 令牌资源 |
| 状态反馈 | 悬停:底色 `Accent.Soft` + 蓝边;按下:再深一档 + 内阴影;禁用:灰字灰底 | `VisualStateManager`(Normal/MouseOver/Pressed/Disabled) |
| 焦点环 | 键盘聚焦 2px `rgba(0,120,215,.35)` 外环;鼠标点击不显环 | `FocusVisualStyle` + `KeyboardNavigation` |
| 强调条 | 分节标题、卡片表头、选中项左侧 3px `Accent.Blue` 竖条 | `Border` 左边框 |
| 过渡动效 | 120ms ease-out(仅底色/边框/阴影);窗口打开 120ms 淡入 | `VisualStateManager` + `Storyboard`(≤150ms) |
| 动效禁用 | 系统"关闭动画"时全部禁用;不做位移动画 | 监听 `SystemParameters.ClientAreaAnimation` |

## 3. 统一窗口框架(所有功能窗共用)

### 3.1 结构

```
┌──────────────────────────────────────────────────────────────┐
│ [提示条:可选,浅黄底,一句话说明本窗用途/注意]                 │  ← 可选
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                     内容区(可纵向滚动)                       │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ [扩展按钮区(左)]                          [确定] [取消(右)]   │  ← 固定底栏
│ 状态文字:xxx                                                  │
└──────────────────────────────────────────────────────────────┘
```

- **底栏左**:本窗特有动作(如"从模型拾取空间""恢复默认参数""导出计算书")。
- **底栏右**:**确定**在左、**取消**在最右(与 Revit/Windows 一致);确定=主操作,取消=关闭不保存。
- 只读展示类窗口(如计算书预览)可把"取消"改为"关闭"。

### 3.2 行为规范

| 项 | 规范 |
|---|---|
| Owner | 必须为 Revit 主窗口(`WindowInteropHelper.Owner`),保证任务栏/焦点行为正确 |
| 模态 | `ShowDialog()` 模态;计算类窗口计算时禁用主按钮并显示忙碌光标 |
| 显示位置 | `CenterOwner`(回退 CenterScreen) |
| 尺寸 | 默认见 §4 各窗;可缩放(`ResizeMode=CanResize`),最小尺寸=默认×0.8;记录上次尺寸(可选) |
| 键盘 | Enter=确定(默认按钮),Esc=取消/关闭,Tab 顺序=视觉顺序 |
| 关闭确认 | 仅当"有未保存的参数修改"时提示"放弃修改?" |
| DPI | 支持 PerMonitorV2;所有尺寸用设备无关单位,不写死像素字体 |

**布局与尺寸**(原型实测)

| 项 | 规格 |
|---|---|
| 面板内排布 | **一行并排,不折行、不堆叠**(`flex-wrap: nowrap`);小系统面板 7 键同样一行 |
| 按钮尺寸 | **68 × 62px**(图标 22×22 + 标签最多 2 行);键间距 4px;面板内边距 10px |
| 标签 | 11px 居中,最多 **2 行**(9 字标签如"全空气一次回风系统"正好 2 行),不省略号截断 |
| 面板名称 | **位于该面板按钮下方、水平居中**(Revit 原生面板标题规格):12px(9pt)、`#4F4F4F`、固定 **14px 名称栏**(各面板基线一致);**不换行**,过长省略号;面板之间用竖向分隔线,**分隔线贯穿面板全高** |
| 面板宽度 | 随按钮数量自适应(1 键 ~88px、7 键 ~520px);面板内边距左右各 10px |
| 整条 Ribbon | 固有宽度约 **1708px**;≥1720px 完整显示;≤1720px 收窄至 **64px** 档(约 1626px);再窄则**横向滚动**(面板仍一行) |
| Ribbon 高度 | 111px(一行排布不增高) |
| 未实现模块 | 统一"待实现说明窗":写清**已定口径**与**待补项**,状态栏红字,**不伪装可用** |

> 说明:Revit 实际执行时面板与按钮由 Revit 排布;窗口变窄 Revit 会折叠整个面板(面板名变为下拉按钮)。原型用"收窄 → 横向滚动"等效演示,不改变"面板内一行"的约束。
> 注:横向滚动时**面板名称随所在面板一起滚动**,右侧面板的名称需要滚动到可见位置;评审建议窗口宽度 ≥1626px(或最大化)。

#### 4.0.1 按钮图标规范(2026-09-11 实装:22 个图标;2026-09-16 增至 23 个)

Revit 侧按钮图标**不是手绘素材**,而是由 `tools/HVACIDA.IconGen` 用矢量几何生成、**内嵌进 `HVACIDA.Revit.dll`** 的 PNG。

| 项 | 规格 |
|---|---|
| 数量 | **23 个**(与 23 个 PushButton 一一对应,键名与 `ModuleCatalog` 一致) |
| 尺寸 | **32×32**(大按钮 `LargeImage`)与 **16×16**(小图标位 `Image`)两套 |
| 绘制方式 | 设计坐标系 32×32、四周留 2px;8 倍超采样后双三次缩放;线宽 1.3–2.0(设计单位) |
| 配色 | 主色深蓝 `#23486E`;底板浅蓝 `#E8F1FA`;强调蓝 `#2E8BD8`;负载语义:负荷=琥珀 `#C8802B`、排烟=红 `#C0392B`、已实现=绿 `#3E8E41`、次要=灰 `#8A8A8A` |
| 风格 | 单色描边 + 极少填充(便于 16px 下仍可辨);**不使用文字/字体**,问号与感叹号用几何绘制,避免字体缺失 |
| 存放 | `src/HVACIDA.Revit/Resources/Icons/<key>_16.png`、`<key>_32.png`(随 DLL 内嵌,`.addin` 只登记 DLL,不会漏拷) |
| 重新生成 | `tools\HVACIDA.IconGen\bin\Debug\net48\HVACIDA.IconGen.exe --out src\HVACIDA.Revit\Resources\Icons`(加 `--preview` 可在无图形界面下打印 ASCII 预览自检) |
| 自检 | `tools\HVACIDA.Smoke\ribbon-smoke.ps1`:校验 22×2 图标齐全、尺寸正确、可解码为已冻结 `ImageSource`、**覆盖率在 5%~90%**(抓"空白图"与"糊成一坨");实测 23.9%~76.6% |

> 设计取向:图标承担"一眼认出模块"的职责,因此**同族同形**(如 6 类小系统都用"箱体+风向箭头"语汇、3 个"计算结果"都用柱状图/仪表),跨面板复用视觉语言;未实现模块**不用灰色禁用感**——它们仍是可点的说明入口。

### 4.2 大系统负荷计算窗口(需求 2.2.3.1 · 默认 1500×860)


- 口径存疑项(空调器冷量口径、排风选型系数、加压单位)一律在窗口红字显示,不静默。

### 4.9 结果获取时机:打开即算 + 计算即保存(2026-09-15 定稿)

评审口径原话:**「计算完成后,直接将结果显示在"计算结果"窗口中,不需要再重新点计算」**。落成四条硬规则:

| 规则 | 内容 | 为什么 |
|---|---|---|
| **① 打开即算** | 以「计算结果」为名的窗,以及带结果区的录入窗(大系统负荷计算窗)**构造时就算一次**:打开就有表、有计算书,不用进来再点一次【计 算】 | 【计 算】按钮的语义从"出结果的开关"变为"刷新"(别的窗改完参数后再点);打开空窗等用户点按钮是缺陷 |
| **② 计算即保存** | 录入窗点【计 算】= **先把本次输入落盘,再计算**(大系统 `large-system.xml`;排烟参数 `large-smoke.xml`;小系统按「类型 + 编号」upsert `small-systems.xml`) | 结果窗读的是已保存数据;只算不存会出现"刚算完、结果窗还是上一次参数"的口径分叉 |
| **③ 内部重算不写盘** | 打开窗、拾取回填、恢复默认等**内部重算**只算不存 | 只是打开看一眼、或拾取后还没核对,不该覆盖已保存参数 |
| **④ 空系统不落盘** | 小系统在没有房间/分区行时点【计 算】**只算不存**,状态栏说明原因(加压送风本就没有房间行,照常保存) | 否则「计算结果」窗汇总里会多出一套 0 房间的空系统,而界面没有"删除系统"入口 |

- **状态栏必须写清这次到底存没存**:存了 → 「本次计算已同时保存(当前工程共 N 套小系统)」;没存 → 「本次没有房间/分区行,未保存(…);补全后点【计 算】会一并保存」;存盘失败 → 「⚠ 参数保存失败(原因),本次结果仅存在于本窗」。**不静默写盘、也不静默不写**。
- 三处按钮 ToolTip 同步写明"计算会同时保存",让"点一下就落盘"这件事在点击前就可见。
- 门禁(`window-smoke.ps1`):断言"打开即出结果"「只是打开不写盘」「点计算即落盘(改 D55=1888 → 计算结果窗读到 1888×60)」「空系统不落盘」以及端到端「录入窗算完 → 汇总窗里就有这套系统」。

> 所以 Excel / 界面 / 文本计算书三者同源。

口径(用户 2026-09-15:「没有具体计算公式,由你实现该功能」—— 用通用公式并把取值全摆出来):

| 环节 | 口径 | 取值来源 |
|---|---|---|
| 流速 | v = Q ÷ 3600 ÷ A(m³/h、m²) | 定义式 |
| 水力直径 | **d = 4A ÷ 湿周**(矩形风管即流速当量直径 2ab/(a+b)) | 与手册比摩阻线算图同口径 |
| 雷诺数 | Re = v·d/ν | ν 按介质 + 温度**查常用物性表**插值(风 20 ℃ 取 1.51e-5、水 10 ℃ 取 1.306e-6) |
| 摩擦系数 | λ = 0.11×(K/d + 68/Re)^0.25(**阿尔特舒利**显式式);Re 小于 2320 时 λ = 64/Re | 通用湍流式 + 层流解析式 |
| 比摩阻 / 沿程 | R = λ/d × ρv²/2(Pa/m);ΔP沿 = R × L | 达西-魏斯巴赫 |
| 局部 | ΔP局 = Σζ × ρv²/2;Σζ 由管件表**逐件累加**到所在管段 | ζ 取手册常用值,**每条都在界面上写明来源并可改** |
| 最不利环路 | 由**模型连接件拓扑**从风机/水泵走到各末端,取累计阻力最大者 | Revit 连接关系;拓扑判不出来时不猜(见下) |
| 需求风压 | (沿程 + 局部 + 环路上末端/设备 + 出口动压)× 富余系数(默认 1.1) | 出口动压 = 出口段 ρv²/2 |
| 需求扬程 | (沿程 + 局部 + 末端/设备 + 静压)× 富余系数 ÷ (ρ·g);静压 = ρg·高差(闭式环路取 0) | 与水泵扬程定义一致 |
| 校核 | 模型读到风机额定全压 / 水泵额定扬程 → 给出**余量 %** 与结论(满足 ≥10% / 偏紧 / 不足);读不到就写「未校核」 | 不编额定值 |
| **并联环路平衡** | 逐支路累计(该支路管段沿程+局部 + 该支路末端/设备)与**最不利环路**比较;**不平衡率 = (最不利 − 该支路) ÷ 最不利 × 100%**,允许值默认 **15%**(可改) | 超限支路给平衡装置参数(见下) |
| 水系统平衡阀 | **Kv = Q ÷ √(ΔP[bar])**(20 ℃ 水,Kv 定义式:压差 1 bar 时 m³/h);**阀权度 S = 需吸收压差 ÷ 最不利环路总阻力** | 支路流量取该支路末端管段流量 |
| 风系统风阀 | **需增加 ζ = 需吸收压差 ÷ (ρv²/2)**(v 取该支路末端管段流速) | 对应多叶调节阀的开度调节 |
| **系统阻力特性曲线** | ΔP(Q) = **静压 + (总阻力 − 静压) × (Q ÷ Q设计)²**(阻力随流量平方变化,**静压不随流量变化**),给出设计流量 50%~130% 每 10% 一点 | ⚠ **与厂家风机/水泵性能曲线的交点才是工况点**;插件不内置设备曲线,不假装算了工况点 |

**数据来源纪律**(与"不猜、不静默"一致):

- 长度 / 断面 / 流量 / 设备参数**一律从模型读**(管段流量取两端连接件的较大者,最保守);
- **管件族名匹配不到系数表** → 不计其局部阻力,但**逐条列进待补提示**(可手工加到管段 Σζ);
- 管件**归属不到管段** → 累计其 ζ 并提示,不静默丢弃;
- 末端/设备**没有阻力参数** → 风口按 ζ×动压估算并写明,水侧没有水阻参数则**按 0 计并提示**(按样本补);
- **最不利环路判不出来**(未成系统 / 系统里没找到风机·水泵 / 环路搜索发散)→ **不标任何标记**,由 Core 按"全部管段之和"保守计入,并在待补说明里写明原因。

**计算结果窗**(「水力计算 → 计算结果」)是**全站多系统汇总**(与「小系统 → 计算结果」同构):汇总表**逐系统一行**
(介质 / 系统编号 / 系统名 / 最不利环路末端 / 环路段数·总段数 / 管段总长 / 设计流量 / 沿程 / 局部 / 末端+设备 /
出口动压 / 静压 / 计算总阻力 / 需求值 / 设备额定值 / 余量 / 并联支路 / 最大不平衡率 / 超限支路 / 校核结论,共 20 列),
选中某行看该系统的逐段明细、环路阻力项、**并联环路平衡表**(支路 / 段数 / 管段 / 末端 / 合计 / 不平衡 Pa·% / 需吸收 /
平衡阀 Kv / 阀权度 / 需增加 ζ / 结论;最不利环路行高亮、超限支路行标红)、**系统阻力特性曲线表**(流量比 / 流量 /

## 5. 与 Revit 模型交互规范

1. **拾取空间**:**关闭本窗 → 命令层拾取 → 用同一 ViewModel 重新开窗**(本节原写"隐藏本窗 `Hide()`",2026-09-12 按实机机制更正,理由见下)→ 状态提示条 → `Selection.PickObjects(ObjectType.Element, filter, 提示语)` 多选,回车结束 → 回填并重开窗;Esc 取消则保留原值并提示"已取消拾取"。
   > **为什么不能只 `Hide()`**:WPF 模态窗(`ShowDialog()`)会在 Win32 层**禁用 Owner 窗口**(此处即 Revit 主窗),而 `Hide()` **不会**恢复 Owner —— 模态循环不结束,模型就一直点不动。
   > 所以拾取只能发生在 `IExternalCommand.Execute` 里"没有模态窗"的那一段:窗口记录拾取目标后关闭 → 命令层调 Revit 选择 API → 结果回填到**同一个 ViewModel** 再重新开窗(用户已填内容不丢)。循环设上限(当前 5 次)。
2. **拾取墙体**(小系统外墙长度):同上,`ISelectionFilter` 只允许墙;支持多选,实时累计长度显示在提示条("已选 3 段,共 32.5 m"),确认后回填。
3. **反馈**:拾取过程中不得有窗口遮挡模型;提示语必须写明"回车结束、Esc 取消"。
4. **失败处理**:拾取到无面积/无高度的空间 → 该空间**不参与合计**并在"模型取值明细"里单列,状态栏说明"该空间缺少面积参数,请在模型中检查";**不得**把 0 或猜测值写进参数。
5. **模型取值不静默**:自动识别按名称关键词分类,被"公共区"口径筛掉的同侧空间(如付费区、风道)与未识别空间**都必须在明细列表里列出**,让"合计有没有漏项"可核对;任何一组都不会被自动并入合计。
6. **计算线程**:同步计算(当前规模秒级);超过 1 秒显示忙碌光标;超过 5 秒显示进度窗(可取消)。

## 7. 校验、错误与进度

| 场景 | 处理 |
|---|---|
| 必填为空(如客流) | 输入框标红 + 底栏错误文字 + 焦点定位到首个错误字段;"计算"仍可点,但结果区提示"缺少必填参数" |
| 数值越界(负数、>阈值) | 同上,提示具体范围 |
| 几何为 0 | 允许计算但结果区提示"站厅/站台面积为 0,结果无意义" |
| 除零/退化(湿负荷=0) | **不弹错**;结果按保护规则(焓差过小记 0)并加灰字说明 |
| 计算异常 | 结果区显示简要错误 + "查看详情"展开堆栈;**不弹系统错误框** |
| 保存失败(文件占用等) | 顶栏红色状态条,保留输入不清空 |
