# HVACIDA 开发流程(团队 + AI 协作版)

> 本文档是项目开发的操作手册:总流程 → 单模块迭代 → 模块状态看板 → 每轮验证清单 → 领域口径记录 → Git 规范。
> 配套阅读:`README.md`(工程结构/编译)、`HVACIDA_需求分析文档.md`(需求)、`大系统负荷计算公式.docx` 及 `-示例.xls`(公式权威输入)。
> 最后更新:2026-09-09(大系统主链算例核对完成)。

---

## 1. 项目级总流程

```
① 需求/公式基线 → ② 模块设计 → ③ 编码(分层) → ④ 编译门禁
→ ⑤ 数值回归 → ⑥ Revit 实机验证 → ⑦ 数据与报表 → ⑧ 集成模块
→ ⑨ 部署分发与验收
```

| 阶段 | 做什么 | 产出/出口标准 |
|---|---|---|
| ① 需求/公式基线 | 把需求文档条目与公式文档(docx/xls)整理成"输入→期望输出" | 每模块一份算例(无算例则列明"待领域确认"项) |
| ② 模块设计 | Models / Service 接口 / 常量(`Utils/HvacConstants.cs`) | 命名空间与需求章节一一对应 |
| ③ 编码 | 固定顺序 **Core(可单测)→ UI(WPF/MVVM)→ Revit(外壳/API)** | 各层职责:Core 无 Revit 依赖;UI 不引用 Revit API;Revit 引用两者 |
| ④ 编译门禁 | VS MSBuild 全解决方案 Debug | **0 错误 0 警告**,三个 DLL 产出 |
| ⑤ 数值回归 | `tools/HVACIDA.Smoke` 加"输入→期望输出"断言 | 与算例逐格一致(现 30 项 PASS);无算例则至少自检无 NaN/负数 |
| ⑥ Revit 实机验证 | 用户本机 `deploy/install.ps1` → 重启 Revit 2020 冒烟 | 见 §6 实机清单 |
| ⑦ 数据与报表 | SQLite 化、计算书 txt→Excel/PDF | 接口不变,实现可替换 |
| ⑧ 集成模块 | 水力(风/水)、材料表、出图、AI 问答 | 按依赖顺序逐个替换占位 |
| ⑨ 部署与验收 | `.addin` 分发(或打包);对照需求文档第 6 章验收 | 验收逐条签字 |

## 2. 单模块迭代循环(每个模块照此执行)

```
规划(读需求+技能 revit-hvac-2020)
   ↓
Core 模型/计算 → 编译 0 错 0 警
   ↓
数值回归用例(算例断言或自检) → 通过
   ↓
UI 表单/VM → XAML 绑定与模型字段一致性校验(见 §5.2)→ 编译
   ↓
Revit 接线(命令/对话框)→ 编译
   ↓
【你】install.ps1 → Revit 实机冒烟(填 §6 清单)
   ↓
领域数值/口径确认(你或专家)→ 固化到 HvacConstants/口径记录(§7)
   ↓
git commit(一条一模块)+ push(你在本机终端执行)
   ↓
README 完成度看板 + 本文档看板打勾 ← 每轮闭环
```

## 5. 质量门禁细则

### 5.1 编译
```powershell
& "C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" .\HVACIDA.sln /t:Build /p:Configuration=Debug /nodeReuse:false /m:1 /v:m
```

### 5.2 WPF 绑定一致性(防"静默留空")
每次改 XAML 后,用反射校验全部 `{Binding Input.X}` 都能命中模型公开属性:
```powershell
$asm=[System.Reflection.Assembly]::LoadFrom("D:\DSH\src\HVACIDA.Core\bin\Debug\net48\HVACIDA.Core.dll")
$props=$asm.GetType("HVACIDA.Core.Models.LargeSystemInput").GetProperties('Public,Instance').Name
[regex]::Matches((Get-Content "src\HVACIDA.UI\Views\LargeSystemWindow.xaml" -Raw),'Binding Input\.([A-Za-z0-9_]+)').Groups[1].Value | Sort-Object -Unique | Where-Object { $_ -notin $props }
```

### 5.3 数值回归
```powershell
# 构建并运行 tools/HVACIDA.Smoke;退出码 0 = 全部断言通过
& "D:\DSH\tools\HVACIDA.Smoke\bin\Debug\net48\HVACIDA.Smoke.exe"
```
新公式/新算例一律先在 Smoke 加断言,不许只靠"肉眼看数字"。

## 8. Git 协作规范

- 提交粒度:**一个模块/一个公式核对 = 一次提交**,message 用 Conventional Commits(`feat|fix|docs|test|refactor` + 作用域 + 中文说明)。
- 版本管理:本地提交可随时做;**push 由你在本机终端执行**(沙箱无认证):
```powershell
cd D:\DSH
git add -A; git commit -m "类型(作用域): 说明"
git push
```
- 涉及公式/数值的文件(尤其是 `HvacConstants.cs`、计算器、算例)改动必须附 §7 记录或算例断言。
