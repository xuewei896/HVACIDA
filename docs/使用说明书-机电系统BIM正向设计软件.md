# 1 软件概述

**机电系统 BIM 正向设计软件**(Revit 功能区名称为「HVACIDA」)是在 Revit 2020 内运行的地铁暖通设计插件。它以模型空间为数据源,把**负荷计算、送排风与排烟、水力计算、材料统计、图纸出图、规范知识检索**串成一条正向设计链:参数从模型来,结果回到模型与计算书里去。

- **正向设计**:面积、层高、外墙长度等几何量直接取自模型空间,不二次录入;
- **算法可核**:所有公式按院《大系统负荷计算公式》《小系统空调负荷、送排风、排烟计算公式》逐条实现,并与文档算例逐格比对;
- **同源输出**:界面表格、文本计算书、Excel 计算书由同一份计算结果渲染,不会出现"界面一个数、计算书另一个数";
- **数据本地化**:工程数据保存在 `%AppData%\HVACIDA\` 下的 XML 文件,换机拷走该目录即可。

## 1.1 运行环境

| 项 | 要求 |
|---|---|
| Revit | Autodesk Revit 2020(64 位) |
| 操作系统 | Windows 10 / 11(64 位) |
| 运行时 | .NET Framework 4.8(Windows 10 及以上自带) |
| 屏幕 | 建议 1920×1080 及以上(表格较宽) |

## 1.2 安装与加载

1. 关闭 Revit;
2. 以管理员身份打开 PowerShell,执行 `deploy\install.ps1`(默认 Debug,正式使用加 `-Configuration Release`);
3. 脚本会编译程序集、在 `C:\ProgramData\Autodesk\Revit\Addins\2020\` 写入 `HVACIDA.addin` 并指向编译输出;
4. 启动 Revit 2020,功能区出现「HVACIDA」选项卡即安装成功;

## 2.1 窗口通用操作

- 窗口顶部是**参数区**,中部是**表格**或**分节录入**,底部是操作栏;
- 【确 定】= **保存并关闭**(不是"仅关闭");【取 消】= 不保存直接关闭;
- 表格里的**可编辑列**可以直接改,改完点【计 算】刷新结果;计算类窗口是**打开即算**;
- 每处说明都收在**悬停提示(ToolTip)**里,鼠标停在标题、按钮或表头即可看到口径。


## 2.2 快速上手(推荐流程)

第一次使用按下面的顺序走一遍;插件里的「AI问答 → 操作指南」窗口也是这七步,可随时点开照做。

[[FIGURE]] docs/manual-images/m-guide.png|16|图 2-2 操作指南窗(推荐流程与常见注意点)

1. **工程信息** → 填工程名称、设计阶段、项目地点、车站名称;
2. **气象参数** → 核对大系统 / 小系统的室外与室内设计参数;
3. **公共区参数** → 拾取站厅 / 站台空间,填写高峰客流(必填);
4. **大系统 → 负荷计算** → 核对参数后点【计 算】;
5. **大系统 → 计算结果** → 看客流、冷负荷、风量与制冷量,导出计算书;
6. **小系统** → 选具体系统类型 → 录入房间、计算、导出计算书;
7. **水力计算 / 出图 / 规范知识库** → 按需使用。

> 每一步都可以取消,不会改动模型;数值口径一律以院公式文档为准。

# 3 项目信息

## 3.1 工程信息

工程信息是后续所有计算书抬头的来源。省份/城市为**省市级联**,选完自动匹配气象台站;车站名称、设计阶段、备注按项目填写。

[[FIGURE]] docs/manual-images/m-project.png|15|图 3-1 工程信息窗

- 【确 定】保存到 `project.xml` 并关闭,结果窗与计算书抬头立即使用新值;
- 车站名称会出现在计算书标题与图框清单里,建议按"××站"填写。

## 3.2 气象参数

气象参数窗分**室外气象参数**与**室内设计参数**两组:大系统与小系统可以取不同的室外计算温度;选定省市后,插件从内置的全国 **294 个台站**气象库自动回填夏季空调干球/湿球温度等。

[[FIGURE]] docs/manual-images/m-weather.png|15|图 3-2 气象参数窗

- 夏季空调干球/湿球温度是负荷计算的边界条件,改动会影响全部系统;
- 室内设计参数按大系统(站厅/站台)与小系统(管理/设备用房)分别给;
- 缺台站记录时保留原值并提示,不会用临近城市猜值。


# 4 大系统(公共区)

## 4.1 公共区参数

公共区参数提供站厅/站台公共区的**面积、层高、长度**与**高峰客流资料**。几何量可由模型自动识别或分两次拾取站厅、站台空间;客流必须手工填写,插件不从模型推断。

[[FIGURE]] docs/manual-images/m-public-area.png|14|图 4-1 公共区参数窗

- 【自动识别全模型空间】按空间名称/标高里的"站厅""站台"分类,同类中优先取名称含"公共区"者;
- 【拾取站厅空间…】【拾取站台空间…】关窗后在模型里框选,回车结束,Esc 取消;
- 勾选"手工输入几何参数"后可直接填数,适用于无模型或空间未放置的情况。

## 4.2 负荷计算

负荷计算窗按公式文档分为 8 个分区、约 66 项参数:围护结构、客流、照明、设备、新风、湿负荷、焓湿过程、选型系数。左列是分区导航,右侧分节录入,底部给出联动结果。

[[FIGURE]] docs/manual-images/m-large-load.png|16|图 4-2 大系统负荷计算窗

- 面积、层高、站厅长度从「公共区参数」带入,客流与设备参数在此填写;
- 送风温差、管道温升、新风比等系数都有文档默认值,可改;
- 点【确 定】前会先保存 `large-system.xml`,再关闭窗口;结果在「计算结果」窗查看。

## 4.3 排烟计算

排烟计算采用"公共区面积 × 60 m³/(h·m²)"口径,选型系数默认 1.2,风机按 2 台取站厅/站台的大者。

[[FIGURE]] docs/manual-images/m-smoke.png|15|图 4-3 排烟计算窗

- 面积只读,来自「公共区参数」;改了面积点【重取面积】即可;
- 表格高亮行即"风机选型基准区",单台风量 = 基准区选型风量 ÷ 台数;
- 同一份数据可在「计算结果」窗导出计算书或 Excel。

## 4.4 计算结果

计算结果窗汇总大系统的**计算参数**与**选型参数**两段,并附负荷与排烟的计算书全文,可一键导出。

[[FIGURE]] docs/manual-images/m-large-result.png|15|图 4-4 大系统计算结果窗

- 打开即算,不需要再点一次"计算";
- 【导出计算书】弹"另存为",生成 Excel 工作簿(计算参数与选型、输入参数、负荷汇总、排烟分区、排烟选型、口径与待补 共 6 页)。


# 5 小系统(设备管理用房)

小系统按六类设备形式分六个入口:**全空气一次回风、多联机+新风、排风、送风排风排烟、加压送风、排烟**。一个系统可录入多个房间/防烟分区,窗口内用左右选项卡管理多套系统(系统编号 1、2、3…)。

## 5.1 全空气一次回风

房间表按**23 列**列出每个房间的数据:序号、房间名称、面积、层高、外墙长度、屋顶面积、设备/照明/人员冷负荷、湿负荷、通风量、换气次数、实际换气次数、新风量、空调器冷量、回风量等。

[[FIGURE]] docs/manual-images/m-small-allair.png|16|图 5-1 全空气一次回风系统窗

- 前段列(名称、面积、层高、设备冷负荷、人数、换气次数…)可直接编辑,后段列自动计算;
- 【从模型拾取空间…】按空间建行并回填面积/层高;【测量外墙长度(两点)…】在模型里量距填入选中行;
- 最下行是本系统合计:总送风量、总回风量、总制冷量、总新风量。

## 5.2 多联机+新风

多联机+新风的房间表按**20 列**列出每个房间,比全空气表多出「室内机台数 / 单台室内机计算冷量 / 单台室内机选型冷量 / 房间选型冷量」四列,表头与院《多联机+新风计算公式-示例.xls》逐字一致。

[[FIGURE]] docs/manual-images/m-small-vrf.png|16|图 5-2 多联机+新风系统窗(左侧列)

[[FIGURE]] docs/manual-images/m-small-vrf-right.png|16|图 5-3 同表右半部分:室内机台数与选型冷量

- 换气次数默认 **6 次/h**(未填、拾取、清空都按 6 计算);
- 室内机台数与**单台室内机选型冷量**是输入项:台数默认 1 台;选型冷量按样本填,留空则按计算值;
- 房间选型冷量 = 台数 × 单台选型冷量;合计行给出**室外机选型冷量** = Σ房间选型 + 新风机组选型。

## 5.3 小系统计算结果

计算结果窗把全站小系统汇总成"逐系统一行",选中某行即可看该系统的房间明细、设备选型与计算书全文。

[[FIGURE]] docs/manual-images/m-small-result.png|16|图 5-4 小系统计算结果窗

- 上部是全站汇总表(系统类型/编号、面积、冷负荷、风量、设备台数);
- 中部是该系统的房间明细(全空气 23 列 / 多联机 20 列);
- 底部是设备编号及选型;【导出全站汇总计算书】【导出全站 Excel】可整站导出。


# 6 水力计算

水力计算用于核算风系统与水系统的**最不利环路阻力**,并给出风机全压、水泵扬程的需求值。打开窗口后从模型读取管网:选系统、读管段、算环路,一步完成。

[[FIGURE]] docs/manual-images/m-hydraulic.png|16|图 6-1 风系统水力计算窗

- 上部是系统参数(系统编号、名称、介质温度、富余系数、粗糙度)与系数表;
- 中部是管段表(断面、长度、流量、ζ 合计、是否在环路)与环路阻力项(末端、设备);
- 下部是计算结果:沿程、局部、末端与出口动压、计算总阻力与需求全压;
- 【计算并保存】【导出计算书】【导出 Excel】;水系统同理,需求值单位换成扬程 m。

## 6.1 水力计算结果

计算结果窗按系统汇总,可逐个查看管段明细、并联环路平衡与系统阻力特性曲线。

[[FIGURE]] docs/manual-images/m-hydraulic-result.png|16|图 6-2 水力计算结果窗

- 全站汇总表逐系统一行:环路管段数、总长、设计流量、沿程/局部/末端与出口动压、计算总阻力;
- 选中系统后给出逐管段明细、并联环路不平衡率与平衡阀 Kv、阻力特性曲线(工况点);
- 汇总只相加"可加量",压力类指标不给合计(各系统管网独立)。


# 7 统计与出图

## 7.1 材料表

材料表统计从模型读取 11 类构件(风管、风管管件、水管、水管管件、设备、保温等),按「类别 + 族 + 类型 + 单位」归并,给出数量、件数与类别小计。

[[FIGURE]] docs/manual-images/m-material.png|16|图 7-1 材料表统计窗

- 单位进入归并键:长度(m)与件数(个)不会互相求和;
- 【导出 Excel】输出可直接用于概算的材料表;
- 图例表复用同一批数据,保证图例与材料表一致。

## 7.2 图框与批量出图

图框窗读取模型中的图纸,列出图纸编号、名称、图框类型、图幅、视图数与是否空图框,并支持批量导出。

[[FIGURE]] docs/manual-images/m-sheets.png|16|图 7-2 图框窗

- 【导出 DWG/DXF】逐张导出;【导出 PDF】走系统打印机;
- 【批量标注空间】在平面视图里批量标注空间名称与编号;
- 【导出清单 Excel】输出图纸清单,便于校审与归档。


# 8 规范检索与 AI 问答

## 8.1 规范知识库

知识库把院内的**计算口径**、**规范条文**与 **Revit 操作指南**条目化:每条有分类、标题、正文与出处,支持全文检索,答不出时明确说"不在范围内",不编条文号。

[[FIGURE]] docs/manual-images/m-knowledge.png|16|图 8-1 规范知识库窗

- 可直接点常用问题(如"小系统全空气怎么算");答案下方列出**出处**,便于追溯;
- 支持导入标准条文电子版(txt/md/csv/docx),导入后可按条文号检索原文;
- 分类筛选:口径 / 规范依据 / 操作步骤 / 数据与存储。

## 8.2 AI 对话

AI 对话窗把大模型接到当前工程:模型可以调用**只读命令**读取模型与计算结果,再回答你的问题;涉及修改模型时,需要两级开关 + Revit 原生确认。

[[FIGURE]] docs/manual-images/m-ai.png|15|图 8-2 AI 对话窗(示例对话)

- 两个开关:"启用 AI 对话"与"允许模型修改模型",默认只读;
- 每次工具调用都逐条列出(命令名、耗时、成功/失败),可审计;
- 未配置密钥或断网时,窗口会明确提示,并可继续用本地知识库。

# 10 常见问题

| 问题 | 处理 |
|---|---|
| 功能区的 HVACIDA 选项卡没出现 | 检查 `C:\ProgramData\Autodesk\Revit\Addins\2020\HVACIDA.addin` 是否存在、Assembly 路径是否指向当前编译输出;重启 Revit |
| 窗内数字与上次不一致 | 录入窗点【计 算】会先保存再算,结果窗读的是保存的那一份;确认当前系统编号 |
| 拾取空间后面积是 0 | 该空间未放置或未计算体积,在 Revit 里"放置空间"后重新拾取 |
| 提示"模型里的风机没有读到额定全压" | 在水力窗手工填风机额定值,或补风机族参数后重算 |
| Excel 打开提示格式 | 计算书为标准 xlsx,若被安全软件拦截,另存到本地磁盘再打开 |
| 换台电脑能用吗 | 拷贝 `%AppData%\HVACIDA\` 到新机同一路径;插件按机器安装 |
| 如何卸载 | 删除 `C:\ProgramData\Autodesk\Revit\Addins\2020\HVACIDA.addin`,工程数据仍保留 |

## 10.1 计算口径纪律

- 公式与系数**一律以院公式文档为准**,示例仅用于理解公式;
- 文档未给的量不擅自外推,拿不准的会在口径说明里如实标注;
- 交付文案不出现单元格编号(如 E99),编号只在代码注释与核对视图里。
