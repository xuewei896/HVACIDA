# 标准条文电子版放这里 / 或放到插件运行时目录

插件**运行时读取**的条文目录是:

```
%AppData%\HVACIDA\规范条文\
```

(在资源管理器地址栏粘贴 `%AppData%\HVACIDA\规范条文` 即可打开;插件会在首次读取时自动创建该目录。)

仓库里的 `docs\规范条文\` 是**同一份内容的版本管理位置**:如果你希望条文随项目一起备份/交接,
把文件也放一份在这里;但**插件读的是 `%AppData%` 那一个**(插件不与仓库路径绑定,换电脑也能用)。

## 支持哪些格式

| 格式 | 支持 | 说明 |
|---|---|---|
| `.txt` / `.md` / `.csv` | ✅ | 纯文本;UTF-8 或 GBK 都能读 |
| `.docx` | ✅ | Word 文档(插件直接解析,不用你另存) |
| `.pdf` | ❌ | 请另存为 `.docx` 或 `.txt`(PDF 解析容易读错条文,所以不做) |
| `.xls` / `.xlsx` | ❌ | 请导出为 `.csv` 或 `.txt` |

## 文件怎么命名

**标准编号 + 名称**,例如:

```
GB 50736-2012 民用建筑供暖通风与空气调节设计规范.docx
GB 51251-2017 建筑防烟排烟系统技术标准.docx
GB 50015-2019 建筑给水排水设计标准.txt
```

插件从**文件名**里取标准编号与名称(并据此猜专业:给排水 / 防烟排烟 / 地铁 / 制图验收 / 通风空调)。
也可以在文件首行写 `#标准:GB 50736-2012 民用建筑供暖通风和空气调节设计规范` 覆盖文件名。

## 条文怎么排(识别规则)

行首以 **`4.1.2`** 或 **`第 4.1.2 条`** 开头的行,视为一条条文的开始;
从这一行往下、直到下一个条文号为止的全部文字,作为这条条文的**原文**。

例如:

```
4.1.2 室内设计温度应符合下列规定:
1 舒适性空调室内设计参数应符合表 4.1.2 的规定;
2 ……

4.1.3 室内设计风速宜符合下列规定:
……
```

插件识别出两条:`4.1.2`(含其下所有文字)与 `4.1.3`。

## 放进去以后怎么用

1. 打开插件 →「AI问答 → 规范知识库」;
2. 点【重新导入条文】(界面上会显示"已从 N 个文件解析出 M 条条文",并列出没解析成功的文件与原因);
3. 之后提问(如「第 4.1.2 条是什么」「室内设计温度怎么规定」)会**优先命中条文原文**,并按分类「规范条文」筛选;
4. 未解析出条文号的文件会**明确列出来**,不会被静默忽略。

## 和「ima 在线知识库」的关系(2026-09-16)

知识库窗里还可以挂一个 **ima 在线知识库**(可选)。两条路各自独立:

| | 本目录(条文电子版导入) | ima 在线知识库 |
|---|---|---|
| 前提 | 你手上有**条文电子版文件** | 你有 ima **开放平台凭证**(Client ID + API Key + 知识库 ID) |
| 返回 | **条文原文**(整条,可检索、可导出 Excel) | 命中条目的**标题 + 命中片段**(不是全文) |
| 联网 | 不需要(全离线) | 需要(HTTPS 调 ima 接口) |
| 配置 | 把文件丢进 `%AppData%\HVACIDA\规范条文` 即可 | 在知识库窗的 ima 面板填凭证并【保存设置】 |

> ⚠ **分享链接里的 shareId 不能当接口凭证**:它只用于在浏览器打开分享页。
> 如果你手上只有 ima 的**分享知识库**而没有开放平台凭证,等价做法是:在 ima 里把条文原文导出/复制出来,
> 按上面「文件怎么命名 + 条文怎么排」整理成本目录里的 `.txt` / `.docx`,再点【重新导入条文】——
> 这样条文原文就进了本地库,离线也能检索,且不涉及任何凭证。
