      操作指南✕
      
  
      
    
      [!] 推荐按 ①→⑥ 顺序操作;每步都可"取消",不改动模型。
      
    
      ① 项目信息(工程信息 + 气象参数)
      
      
      填工程基本信息;气象参数可整表导入 Excel 模板,或从气象数据库获取
      
      
      确定后写入当前 .rvt 全局参数(模型元数据)
      
    
      
    
      ② 大系统 → 公共区参数
      
      
      从模型拾取站厅/站台公共区空间(面积 D55/D56、层高 C13、长度 C14);填高峰客流
      
      
      客流为必填,缺失时标红并阻止计算
      
    
      
    
      ③ 大系统 → 负荷计算 / 计算结果
      
      
      核对七节参数(可用「默认参数…」恢复公式文档值)→「计 算」
      
      
      客流、分项冷负荷、风量与制冷量、设备选型;可导出计算书
      
    
      
    
      ④ 小系统 → 六类系统按钮
      
      
      点具体系统类型直达计算窗(如全空气一次回风):选空间 → 改参数 →「计 算」
      
      
      外墙长度可「拾取…」多选累计;系统类型在窗内只读(由 Ribbon 决定)
      
    
      
    
      ⑤ 水力计算 / 出图(骨架)
      
      
      风系统、水系统水力计算与明细表、图框出图
      
      
      仅布局骨架,算法未实现(不伪装可用)
      
    
      
    
      ⑥ AI问答 / 产品支持
      
      
      问设计口径(送风温差、排烟、新风、焓湿、屏蔽门…)
      
      
      反馈问题;查看版本、日志路径与快捷键
